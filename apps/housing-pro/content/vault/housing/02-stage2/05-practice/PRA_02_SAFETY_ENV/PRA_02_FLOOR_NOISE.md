# 공동주택 층간소음 (범위 · 주간/야간 dB 기준 · 관리위원회)

## 핵심 특징
- 직접충격 소음(1분 등가소음도 Leq): 주간(06~22시) 39dB / 야간(22~06시) 34dB (최고소음도 Lmax: 주간 57dB / 야간 52dB)
- 공기전달 소음(5분 등가소음도 Leq): 주간 45dB / 야간 40dB (TV·음향기기·악기 등)
- 층간소음 제외 항목: 욕실·화장실·다용도실 급배수 소음! / 700세대 이상 단지는 층간소음관리위원회 의무 구성

## 기출 함정
- 강화된 직접충격 소음 기준 '주간 39dB / 야간 34dB'(구 43/38dB)과 '급배수 소음은 층간소음에서 제외' 함정이 초빈출입니다!

## 소장Pro 실무 팁
- 층간소음 민원 접수 시 즉시 사실 확인·권고 기록을 남기고, 미해결 시 환경부 층간소음 이웃사이센터 측정 연계를 안내하세요.
