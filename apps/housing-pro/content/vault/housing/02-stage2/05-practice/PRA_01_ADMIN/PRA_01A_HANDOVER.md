# 공동주택 관리업무 인수 · 인계 (사업주체 → 관리주체)

## 핵심 특징
- 사업주체 관리기간: 입주예정자 과반수 입주 시 입주자등에게 관리 요구 통지 → 통지 후 3개월 내 입대의 구성 → 관리방법 결정 통지 후 1개월 이내 인계
- 인계 서류 필수 5종: 설계도서·장비명세서 · 장기수선계획서 · 안전관리계획서 · 입주자명부 · 관리비 예치금 명세
- 인계 시 입회: 입주자대표회의 회장 + 1명 이상의 감사가 참관하여 인계자·인수자 서명·날인

## 기출 함정
- 입대의 구성 기한 '3개월 이내', 사업주체→관리주체 인계 기한 '1개월 이내', 인수인계 입회자는 '회장 + 감사 1명 이상'입니다!

## 소장Pro 실무 팁
- 준공도면(건축·기계·전기·소방)과 장비 보증서·하자보수보증서 원본 누락 여부를 체크리스트로 검수하세요.
