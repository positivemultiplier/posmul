## 2. 현재 시스템의 장점과 한계점 (Gap Analysis)

### 2.1 현재 시스템의 강력한 장점 (Strengths)
1. **견고한 오라클 아키텍처 (`settlement-orchestrator.service.ts`)**:
   * 이미 `DART`, `KOSIS`, `ECOS`, `KOBIS`, `Football-Data`, `Alpha Vantage`, `FMP` 7대 어댑터 구조가 인터페이스 기반으로 정교하게 구현되어 있습니다.
   * 크론 파이프라인(`api/cron/prediction-pipeline/route.ts`)이 뼈대로 잡혀 있습니다.
2. **공식 API 키 보유**:
   * DART, KOSIS, Alpha Vantage, FMP, Football-Data 등의 실물 API 키가 이미 `.env.local`에 등록되어 있습니다.

### 2.2 현재 시스템의 결정적 한계점 (Pain Points)
1. **"전문직 학습(주택관리사/세무)"과 "법률 판례" 데이터가 완전히 비어 있음 (0%)**:
   * 축구, 박스오피스, 개별 주가는 대중적이지만, **수험생과 전문직이 매일 아침 목숨 걸고 들어올 '법률 개정안 및 대법원 판례' 소스가 전무**합니다.
   * ➔ `law.go.kr` 및 대법원 판결문 오픈데이터를 연동해야 대표님의 '모닝 10' 비전이 완성됩니다.
2. **글로벌 트렌드 예측 소스의 부재**:
   * 주식 가격만 맞추는 건 증권 앱과 다를 바가 없어 지루해질 수 있습니다.
   * `Polymarket API`를 통해 글로벌에서 수천억 원이 베팅되는 가장 핫한 시사/암호화폐/글로벌 쟁점 확률을 가져와야 진짜 예측 플랫폼다운 도파민이 터집니다.
3. **일상 기후/생활 데이터 부재**:
   * 누구나 직관적으로 맞출 수 있는 "내일 첫눈/한파" 같은 생활 밀착형 퀴즈가 빠져 있습니다.

## 3. 대표님의 비전을 위한 [신규 4대 킬러 데이터 소스] 상세 연동 계획

### ① [최우선] 학업·자격증 & 직무 커리어 공공데이터 (Study & Career Engine)
* **목적**: 전 국민 맞춤형(학생/취준생/직장인/자격증 준비생) 아침 `모닝 10` 일일 퀴즈 원천
* **제공 데이터 소스**:
  * 법제처 국가법령정보 & 대법원 판례 (`open.law.go.kr`): 주택관리사, 공인중개사, 세무사, 생활 법률
  * Q-Net 한국산업인력공단 자격시험 API (`data.go.kr`): 국가기술자격증(기사, 산업기사 등) 기출
  * 고용노동부 노동법령 및 표준근로 상식: 직장인 근로기준법, 연차, 퇴직금, 주휴수당
  * 국사편찬위원회 / 공공 기출: 공무원, 한국사능력검정시험
* **구현될 게임 (유저 맞춤형)**:
  * [주택관리사/부동산 트랙] *"아파트 입주자대표회의 횡령 성립 여부에 대한 판결 예측"*
  * [직장인/커리어 트랙] *"권고사직 vs 자진퇴사 시 실업급여 수급 자격 O/X"*
  * [자격증/취준생 트랙] *"전기기사/정보처리기사 2026 핵심 기출 오라클"*
* **비용**: **완전 무료 (공공데이터포털 + 법제처)**

### ② [글로벌 바이럴] Polymarket 실시간 예측 마켓 API
* **목적**: 글로벌 1위 예측 시장의 핫이슈를 한국어 PosMul 마켓으로 실시간 미러링
* **제공 API**: `https://clob.polymarket.com/markets` (공개 REST API, 키 발급 불필요)
* **구현될 게임**:
  * *"미 연준 12월 기준금리 0.25%p 인하 확률 (현재 글로벌 68%)"*
  * *"비트코인 연내 10만 달러 돌파 여부"*
* **비용**: **완전 무료**

### ③ [생활 도파민] 기상청 공공데이터 & Open-Meteo API
* **목적**: 출퇴근길 누구나 3초 만에 참여하는 국민 참여형 예측
* **제공 API**: `api.open-meteo.com` (키 불필요 오픈소스) 또는 기상청 단기예보
* **구현될 게임**:
  * *"내일 서울 영하 10도 이하 한파경보 발효될까?"*
  * *"이번 주말 중부지방 첫눈 관측 여부"*
* **비용**: **완전 무료**

### ④ [AI 브리핑 엔진] 언론사 공식 RSS 3대장
* **목적**: 네이버/다음 제휴비 없이 실시간 팩트 기반 [중립 + 찬성 + 반대] 3단 균형 브리핑 자동 작성
* **제공 피드**:
  * 연합뉴스 경제 RSS (`yna.co.kr/rss/economy.xml`)
  * 매일경제 / 한국경제 증권·부동산 RSS
  * 대한민국 정책브리핑 RSS (`korea.kr/rss/policy.xml`)
* **비용**: **완전 무료 (합법적 XML 표준 규격)**
