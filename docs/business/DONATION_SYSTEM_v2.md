# PosMul 소셜 임팩트 기부 시스템 v2 (Donation Domain v2)

> **"시민이 직접 예산 집행을 훈련하고, 기부가 다시 한국 경제의 승수(Multiplier)로 돌아오는 선순환 생태계"**

---

## 1. 개요 및 비전

### 1.1 PosMul 경제 사이클에서의 역할
기부(Donation)는 PosMul 전체 경제 생태계의 **최종 목적지이자 가장 숭고한 가치 실현의 장**입니다.
```
[ 1. 학습 (PMP) ]  ──>  [ 2. 예측 훈련 ]  ──>  [ 3. 보상 (PMC) ]  ──>  [ 4. 기부 (시민 직접 예산 집행) ]
   (뉴스/포럼/퀴즈)      (시사/경제 집단지성)      (MoneyWave 상금)       (4대 소셜 임팩트 펀드)
```
- **기존 기부와의 근본적 차이**:
  - 기존 기부는 개인이 번 현금을 일방적으로 털어 넣는 '일방적 자선(Charity)'이었습니다.
  - PosMul의 기부는 **시민이 지적 훈련과 예측 성공을 통해 획득한 위험 자산(PMC)을 바탕으로, "어디에 사회적 자본을 흘려보낼 것인가"를 직접 결정하는 직접민주주의 예산 집행 훈련**입니다.

## 2. 4대 기부 필러(Pillars) 상세 스펙

```
                       [ PosMul 소셜 임팩트 기부센터 ]
                                      │
    ┌──────────────────┬──────────────┴──────────────┬──────────────────┐
    ▼                  ▼                             ▼                  ▼
1. K-임팩트        2. 마일스톤 검증 NGO          3. 숨은 의인 포상제    4. 꿈의 사다리
 [물품직접기부]     [투명 에스크로 파트너십]       [소셜 스카우터 채용]   [Pay-it-Forward]
```

---

### Pillar 1: 📦 K-임팩트 물품직접기부 (Tied Aid & Export Multiplier)
> **"기부금이 한국 기업의 실물 매출이 되고, 국가 수출을 견인하는 승수 모델"**

1. **글로벌 벤치마크 (영국·독일의 구속성 원조 Tied Aid)**:
   - 선진국은 대외 원조 시 현금을 주지 않고, 자국 기업의 물품(정수기, 발전기, 통신장비, 의약품)을 구매하여 지원함으로써 원조와 수출 증대를 동시에 달성합니다.
2. **PosMul 실행 메커니즘**:
   - 시민이 모금한 PMC 기부금으로 **대한민국 제조 기업의 실물 완제품을 대량 구매**하여 국내외 구호 대상에 직접 배송.
   - **대상 품목군**:
     - **K-가전 (LG·삼성 등)**: 고효율 냉장고, 세탁기, 제습기, 공기청정기 (국내 취약계층 복지관, 조손가정 지원)
     - **K-푸드 (CJ·농심·오뚜기 등)**: 햇반, 라면, 통조림, 즉석 영양식 (국내 결식아동 및 글로벌 재난 지역)
     - **K-위생·방역 (유한킴벌리 등)**: 생리대, 기저귀, 마스크, 방역 키트 (자립준비여성, 미혼모 시설)
3. **경제적 승수 효과 (Multiplier Effect)**:
   - 기부금 1억 원 = **한국 중견·대기업 실물 매출 1억 원 창출 + 고용 유지**.
   - 해당 기업은 PosMul의 철학에 공감하여 **MoneyWave Wave 3 (ESG 기업 파트너십)** 기금으로 후원금을 재투입하는 완벽한 선순환 리사이클링 완성.

### Pillar 2: 🤝 마일스톤 검증형 NGO 파트너십 (Proof of Impact)
> **"깜깜이 기부는 끝, 단계별 실행 영수증과 사진이 검증되어야 다음 기부금이 집행된다"**

1. **기존 기부의 문제점 해결**:
   - 기존 대형 재단들의 운영비 과다 지출 및 불투명성으로 인한 기부 포비아 해소.
2. **스마트 에스크로 & 3단계 마일스톤 집행**:
   - 초록우산, 사랑의열매, 국경없는의사회 등 공인 NGO와 제휴.
   - 모금 완료 시 기부금을 한 번에 일괄 지급하지 않고 **30% → 40% → 30%**로 분할 지급:
     - **Step 1 (착수금 30%)**: 프로젝트 기획 및 수혜자 선정.
     - **Step 2 (중간 집행 40%)**: 현장 구호 사진, 물품 구입 영수증을 PosMul 포럼에 공개 ➔ **시민 60% 이상 투표 승인 시 릴리즈**.
     - **Step 3 (최종 정산 30%)**: 최종 감사 보고서 및 수혜자 감사 편지 등록 시 최종 릴리즈.
3. **투명성 인증 뱃지**:
   - 마일스톤을 100% 투명하게 이행한 단체에는 `[PosMul 공인 투명 임팩트 파트너]` 뱃지 부여.

### Pillar 3: 🦸‍♂️ 숨은 의인(義人) 포상제 & 소셜 스카우터
> **"사회의 영웅에게 비과세 포상금을, 청년에게는 '의인 발굴가' 일자리를"**

1. **고용 창출: '소셜 스카우터(Social Scout)' 채용**:
   - 언론에 잘 알려지지 않은 전국의 숨은 의인(화재 현장에서 이웃을 구한 청년, 10년간 결식아동에게 무료 급식을 제공한 식당 사장님 등)을 전문적으로 탐문하고 취재하는 **청년 활동가/인턴을 정식 고용**.
   - 스카우터가 취재한 '의인 리포트'를 PosMul 갤러리에 발행하여 시민 공론화.
2. **⚖️ 증여세·소득세 비과세 법적 제도 설계**:
   - **법적 근거**: **소득세법 시행령 제18조 제1항 제1호**  
     *"공익을 목적으로 제정된 상금과 부상(포상금)은 비과세 기타소득에 해당한다."*
   - 개인 간 직접 증여 시 발생하는 증여세 리스크를 원천 차단하기 위해, 개인 송금이 아닌 **`[PosMul 이달의 의인상]` 공익 포상금 제도**로 공인 지급.
   - **수혜자 혜택**: 세금 공제 없이 **상금 100% 전액 수령** 가능.

---

### Pillar 4: 🌱 꿈의 사다리 페이잇포워드 (Pay-it-Forward Microfinance)
> **"대출이 아닌 꿈의 사다리, 성공하면 다음 사람을 위해 자발적으로 돌려준다"**

1. **글로벌 벤치마크 (Kiva & 그라민 은행 모델)**:
   - 노벨평화상 무함마드 유누스의 서민금융을 웹 플랫폼으로 구현.
   - 자립준비청년(보육원 출신), 청년 소상공인, 인디 예술가, 과학 꿈나무의 프로젝트에 무이자 시민 펀딩.
2. **자발적 상환 (Pay-it-Forward) 메커니즘**:
   - 대부업법 및 이자 규제를 원천 배제하기 위해, 법적 채무 관계가 아닌 **"성공 시 다음 후배를 위해 같은 금액을 자발적으로 재기부한다"는 도덕적 계약 체결**.
3. **상환율 95% 이상을 달성하는 3대 심리적 장치**:
   - **명예의 전당 (Hall of Fame)**: 상환 완료 시 플랫폼 메인에 '꿈을 이룬 선배 멘토'로 영구 헌액.
   - **상환금 승계 투명 시각화**: 내가 갚은 PMC가 다음 어떤 청년의 꿈에 들어갔는지 실시간 알림.
   - **엔젤 기부자 지위**: 향후 플랫폼 내 프리미엄 커뮤니티 의결권(PMG) 부여.

## 3. 기부자 인센티브 (Gamification & Social Honor)

시민들이 적극적으로 PMC를 기부하도록 만드는 인센티브 구조:
1. **소셜 임팩트 스코어 (SIS - Social Impact Score)**:
   - 누적 기부 PMC에 따라 시민 등급 상승:
     - `시민(Citizen)` ➔ `탐구자(Seeker)` ➔ `수호자(Guardian)` ➔ `변혁가(Changemaker)` ➔ `국가적 영웅(National Hero)`
2. **베팅 및 포럼 인증 뱃지**:
   - 예측 게임과 포럼 갤러리에서 닉네임 옆에 황금빛 `[기부 엔젤 뱃지]`가 노출되어 커뮤니티 내 압도적 신뢰도 획득.
3. **세제 혜택 (Tax Deduction)**:
   - 지정기부금단체 연계를 통한 연말정산 기부금 소득공제 영수증 발행.

## 4. 데이터베이스 확장 계획 (Schema Specification)

```sql
-- 1. 기부 프로젝트 테이블 (4대 필러 확장)
ALTER TABLE donation.donations ADD COLUMN IF NOT EXISTS pillar_type VARCHAR(50) DEFAULT 'TIED_GOODS';
-- 'TIED_GOODS' (물품기부), 'NGO_MILESTONE' (NGO검증), 'HERO_BOUNTY' (의인포상), 'DREAM_LADDER' (꿈사다리)

-- 2. 마일스톤 검증 테이블
CREATE TABLE IF NOT EXISTS donation.donation_milestones (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    donation_id UUID REFERENCES donation.donations(id) ON DELETE CASCADE,
    step_number INT NOT NULL, -- 1, 2, 3
    title VARCHAR(200) NOT NULL,
    payout_percentage INT NOT NULL, -- 30, 40, 30
    proof_images TEXT[] DEFAULT '{}',
    receipt_urls TEXT[] DEFAULT '{}',
    status VARCHAR(50) DEFAULT 'PENDING', -- PENDING, IN_VOTING, APPROVED, PAID
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. 꿈사다리 자발적 상환 트래킹 테이블
CREATE TABLE IF NOT EXISTS donation.dream_repayments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    donation_id UUID REFERENCES donation.donations(id) ON DELETE CASCADE,
    beneficiary_id UUID REFERENCES "user".users(id),
    target_amount NUMERIC NOT NULL,
    repaid_amount NUMERIC DEFAULT 0,
    next_recipient_donation_id UUID REFERENCES donation.donations(id),
    status VARCHAR(50) DEFAULT 'IN_PROGRESS', -- IN_PROGRESS, COMPLETED
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 5. 실행 로드맵 (Execution Roadmap)

1. **Phase 1 (기획 및 정식 문서화 - 현재 완료)**:
   - `DONATION_SYSTEM_v2.md` 정식 규격 제정 및 비즈니스 연계.
2. **Phase 2 (UI 개편 - `/donation`)**:
   - 기존의 밋밋한 기부 목록을 **"4대 소셜 임팩트 펀드 셀렉터"**로 전면 리뉴얼.
   - 각 프로젝트별 [K-가전/식품 물품 견적서], [마일스톤 진행도], [의인 사연] 뷰 탑재.
3. **Phase 3 (Pay-it-Forward 시스템 구축)**:
   - 청년 꿈 프로젝트 신청 및 자발적 상환 명예의 전당 연동.
4. **Phase 4 (기업 ESG 파트너십 및 ODA 연계)**:
   - 한국 대기업(가전/식품) 물품 조달 계약 및 MoneyWave 3단계 펀드 풀 확보.
