# Prediction Detail Page UX 레이아웃 제안서

> **핵심 이슈**: 현재의 "탭 분리(예측/차트/정보)" 방식이 과연 최선인가? 사용자가 예측을 수행하는 데 있어 방해가 되지는 않는가?
> **목표**: 사용자 경험(Flow)과 정보의 밀도, 그리고 '게임의 재미'를 극대화할 수 있는 최적의 레이아웃 도출.

---

## 🛑 문제점 진단 (Current Tab Approach)

현재의 `탭(Tab)` 방식은 **"정보 단절"**을 초래합니다.
*   **시나리오**: 사용자가 차트(추세)를 보며 "지금이 기회다!"라고 느꼈습니다. -> 배팅을 하려면 `예측하기` 탭으로 이동해야 합니다. -> 이동하는 순간 차트가 사라집니다. -> **판단의 근거(차트)와 행동(배팅)이 분리**됩니다.
*   **경쟁사(Polymarket, Kalshi)**: 차트와 배팅 패널을 **절대 분리하지 않습니다.** 한 화면에 동시에 상호작용합니다.

---

## 🎨 제안 옵션 (3가지 안)

### 🥇 옵션 A: 통합 대시보드형 (Pro-Trader Style)
> **Polymarket / 주식거래소 방식. "차트를 보며 즉시 배팅한다."**

*   **레이아웃 (Desktop)**:
    *   **좌측 (65%)**: [ 대형 차트 (Recharts) ] + [ 하단: 게임 정보/뉴스 ]
    *   **우측 (35%)**: [ Sticky 배팅 패널 (주문창) ] + [ 내 포지션 현황 ]
*   **레이아웃 (Mobile)**:
    *   **상단**: [ 차트 (높이 고정) ]
    *   **중단**: [ 탭: 정보 / 댓글 / 내역 ] (배팅 패널 제외한 정보만 탭 처리)
    *   **하단 고정 (Sticky Bottom)**: [ "Y 구매" | "N 구매" ] 버튼 (언제나 접근 가능)
*   **장점**: 정보와 행동의 일치. 전문적이고 신뢰감을 줌. 리텐션(체류시간) 증가.
*   **단점**: 모바일 화면 공간이 좁아 정보 배치가 까다로움. 초보자에게 복잡해 보일 수 있음.
*   **추천 대상**: 승무패, 랭킹 게임 등 **전략적 판단**이 중요한 게임.

### 🥈 옵션 B: 단계별 몰입형 (Storytelling Style) - *현재 구조의 발전형*
> **Airbnb / 게임 튜토리얼 방식. "읽고, 보고, 결정한다."**

*   **레이아웃**: 스크롤 기반의 원페이지(One-Page) 또는 명확한 탭 유지.
    *   **Step 1 (상단)**: [ 시나리오/질문 ] (예: "트럼프가 당선될까요?")
    *   **Step 2 (중단)**: [ 핵심 통계/차트 ] (간소화된 Sparkline)
    *   **Step 3 (하단)**: [ 대형 배팅 카드 ] (게임 아이템 구매하듯이)
*   **장점**: 매우 쉽고 친절함. '게임' 같은 느낌을 주기 좋음(Gamification).
*   **단점**: 반복적인 배팅(단타)을 하기엔 동선이 너무김. 정보를 깊게 보기 어려움.
*   **추천 대상**: **이벤트성 단발 예측** (예: 선거, 월드컵 결승).

### 🥉 옵션 C: 하이브리드 (Modern Split) - *강력 추천*
> **Kalshi / 최신 핀테크 앱 방식. "핵심은 고정, 상세는 탐색."**

*   **구조**:
    *   **헤더**: 타이틀 + 현재 스코어 (고정)
    *   **메인 영역 (상단)**: **차트 + 배팅 컨트롤러 통합** (가장 중요한 부분)
    *   **서브 영역 (하단)**: `정보` | `댓글` | `내역` | `관련 뉴스` 탭
*   **핵심**: 배팅과 차트는 탭에 넣지 않고 **항상 노출(Always Visible)**. 덜 중요한(정보, 댓글) 것만 탭이나 아코디언으로 내림.
*   **모바일 UX**:
    *   상단에 차트와 현재가 표시.
    *   하단 Sheet(Bottom Sheet)로 배팅 창을 언제든 끌어올릴 수 있음.

## 🗳️ 비교 및 추천

| 특징 | 옵션 A (통합 대시보드) | 옵션 B (단계별 몰입) | 옵션 C (하이브리드) |
| :--- | :---: | :---: | :---: |
| **난이도** | 상 (구현 복잡) | 하 (구현 쉬움) | 중 (모바일 대응 필요) |
| **정보 전달** | ⭐⭐⭐ (완벽) | ⭐ (단절됨) | ⭐⭐ (균형) |
| **재미/몰입** | ⭐ (건조함) | ⭐⭐⭐ (게임 같음) | ⭐⭐ (세련됨) |
| **모바일 UX** | ⚠️ (복잡) | ⭐ (편안) | ⭐⭐ (최적) |
| **PosMul 적합도** | 70% | 50% | **95%** |

### 🚀 결론: [옵션 C (하이브리드)] 추천
PosMul은 "재미(PMP)"와 "경제(PMC)"를 모두 잡아야 합니다.
1.  **탭을 없애지 않되, 역할 재정의**: `차트`와 `배팅`은 탭에서 꺼내서 **최상단 메인 컨텐츠**로 통합합니다.
2.  **탭 활용**: `상세 규칙`, `참여자 분포`, `포럼 토론(댓글)` 등 부가 정보는 하단 탭으로 구성하여 깔끔하게 정리합니다.
3.  이 구조는 **전문성을 주면서도(상단 차트) 게임성(하단 커뮤니티)**을 잃지 않는 가장 균형 잡힌 접근입니다.
