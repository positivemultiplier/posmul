2. 6대 도메인 참모 헌법 요약표

도메인 한 줄 철학 (존재 이유) 절대 원칙 & 금지선 오픈 단계
Forum (광장) 트래픽·체류시간을 만들고 재도전 PMP를 공급 오직 PMP만 지급 · 일일 상한 1,000 PMP · 추천(+20)·개념글(+100) 우대 · 자추/중복 금지 Phase 1
Consume (광고) 현금 연료(EAT)와 기업 Social(IFRS S1) 생성 유저는 PMP만 획득 · 일반광고(EAT) vs 직접의뢰(Social 지표) 분리 · 소상공인 잠금 트랙A: P1 트랙B: P2 로컬: P3
Economy (원장) 적자 방지용 이중 화폐 원장과 총량 분배기 PMC는 예측 성공으로만 생성 · EBIT 금지, 세후 EAT 기준 · 원장 차감/롤백 원자성 Phase 1
Prediction (심장) 도박이 아닌 1단계 사실·확률 판단 훈련장 승자독식(실패 시 PMP 소멸) · 양쪽 균형 근거 · 공인 오라클 정산 · 도박 용어 금지 Phase 1
Donation (결실) 즐거운 기부와 2단계 가치 배분 훈련 실원장 pmc_balance 차감 · 물품요청·전달·수혜 인증 · 미래꿈에만 콩도르세·보르다 투표 기관·물품: P1 팔로잉·꿈: P2
Ranking (명예) 돈이 아닌 예측 실력과 선한 영향력 평판 읍면동 풀뿌리 · 직업군별 명예의 전당 · Brier Score 실력 평판 (Consume 점수 v3 정렬) Phase 1
단계별 로드맵 & 오픈 이슈: Phase 1(모두의창업 상금 + CPC/CPV/CPA → Forum·Consume → Prediction → 기관·K-물품) | Phase 2(직접광고 Social IFRS S1 + 팔로잉·미래꿈 투표) | Phase 3(블록체인·삼식부기 + 소상공인)  —  미해결 숙제: 외부 타 기관 중복 수령 방지(어금니 아빠 리스크) · Forum 세부 포인트 비율 · 창업상금 월별 기준 · IFRS S1 표준 지표
